# Skill: Browser Testing

Choose one critical journey, prepare deterministic data, run it at desktop and mobile sizes, and record evidence. Check keyboard navigation, visible errors, network failures, and the final persisted result. Keep browser tests independent and do not hide backend failures with mocks when integration is the behavior under test.
