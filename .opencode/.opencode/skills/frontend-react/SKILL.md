# Skill: React Frontend Engineering

Start from the user flow and contract. Implement loading, empty, validation, success, and error states. Keep components feature-oriented, state explicit, and API data typed at the boundary. Use semantic HTML, keyboard support, responsive layout, and the existing design system.

Test behavior rather than implementation details. Do not polish visual details while the contract or core logic is still changing.
