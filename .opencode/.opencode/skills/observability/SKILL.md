# Skill: Observability

Answer: is the service up, is the request succeeding, and why did it fail? Use structured logs with request identifiers, safe error boundaries, health/readiness checks, and the smallest useful metrics. Define what action an alert should trigger; do not add telemetry with no operational purpose.
