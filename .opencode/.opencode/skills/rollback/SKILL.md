# Skill: Rollback and Recovery

Identify the failure signal, last known good version, reversible application changes, migration strategy, data compatibility, owner, and verification after rollback. Prefer backward-compatible migrations and feature flags. A rollback plan must be executable, not only a sentence in release notes.
