# Skill: Security and Hardening

Check trust boundaries, input validation, authorization, authentication, secrets, injection, sensitive data, dependency risk, logging, rate limits, and safe error responses.

Use the least privilege and safest default. Do not invent credentials or fetch private data without consent. Turn each meaningful risk into a test, mitigation, or explicitly documented residual risk.
