# Skill: Ship With Confidence

1. Confirm scope and review status.
2. Run the required tests, build, type check, lint, and security checks once after the final change.
3. Inspect status and diff; exclude secrets, generated noise, and unrelated edits.
4. Create an atomic, attributable commit.
5. Record deployment, migration, rollback, and monitoring notes when relevant.
6. Push only to the authorized remote and report the exact commit and verification evidence.
