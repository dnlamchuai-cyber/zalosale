# Vibe Coding Kit - Documentation Index

These documents are reusable across web, mobile, backend, data, and automation projects. Files that mention BeShort are worked examples, not requirements for a new project.

## Start here

1. `../AGENTS.md` - operating rules, boundaries, and automatic skill routing
2. `_meta/PROJECT_CONTEXT.template.md` - context template for any project
3. `00_WORKFLOW.md` - lifecycle from idea to shipped change
4. `01_TECH_STACK.md` - choose technology with explicit trade-offs
5. `SOLO_STARTER.md` - short setup path for an individual developer

## Lifecycle

| Stage | Documents | Main result |
| --- | --- | --- |
| Define | `02_BUSINESS/` | Problem, users, rules, acceptance criteria |
| Plan | `03_SPEC/`, `05_TASKS/` | Contract, risks, and small implementation tasks |
| Build | `04_PROMPTS/`, `08_TESTING.md` | Executable prompt and tested slice |
| Review | `06_REVIEW/`, `07_WORKLOG/` | Findings, decisions, and evidence |
| Learn | `13_SELF_LEARNING_GUIDE.md`, `15_HOC_VIBE.md` | Durable understanding |
| Ship | `12_BAO_MAT.md`, `17_GIT_VERSIONING.md` | Secure, attributable release |
